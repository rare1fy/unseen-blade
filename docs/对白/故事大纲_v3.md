# 《不见刀》故事大纲 v3（11-19，待用户定）

用户定的三条：开场必败战打崔玄（直闯崔府）；时间压在一两年内、不写年份；崔玄是她亲生父亲，第四关周默临死说破。

## 不变的底子

- 寒山坞文家铸刀，替洛阳权贵打了三十柄百辟刀。腊月廿三那夜，她亲手救活的「洛阳名士」周默在门里抽掉铁栓，放四个人进坞：**石雷**踹翻锻炉，红炭热灰泼了她一脸，她瞎了；**阎虎**把她娘推进高炉；**封寒**事先在井里下药，事后割下铁匠的右手拇指交差；**周默**清点三十柄刀装车。她躲在风箱下，听见这四个名字。
- 那夜之后她只叫刘白。七年里练成听声出刀。她听得出每一柄文家刀出鞘的声音。
- 她后来查到的只有一件事：三十柄刀最后进了**许都崔府**，买主是司空长史**崔玄**。她不知道他是谁，只当他是收赃的那个人。

## 崔玄和刘白：前因后果

按时间顺序（只写「那年」「七年前」，不写年份）：

1. **娘和崔玄**：她娘是许都崔府的乐伎，年轻的崔玄和她有了私情。她怀了孩子，崔玄给孩子起好了名字叫「皎」。这时崔家要和另一家门阀结亲，一个乐伎怀着长子是门第的丑事。崔玄让人给她送去一碗落胎药。
2. **逃进寒山坞**：她没喝那碗药，连夜逃出崔府，一路逃进汝南深山，倒在寒山坞门口。铸刀的文冶收留了她，后来娶了她。孩子生下来随文家姓，名字仍叫「皎」，娘没改。文冶知道孩子不是自己的，当亲生女儿养大。阿皎什么都不知道。
3. **订刀**：十一年后乱世将起，崔玄要三十柄能斩开官军铁甲的好刀，拿去结交各路豪强。他的门客周默（挂着尚方的官职）替他找到了天下最好的铸刀坞，就是寒山坞。周默进坞订刀时认出了文家娘子：她就是当年从崔府逃走的那个乐伎。
4. **灭门的命令**：周默回去禀报。崔玄下了一道命令，里面有两件事：刀成之后坞里一个不留，免得「私铸甲兵」的事传出去；那个女人和孩子一起烧掉，不留门第的丑事。周默扮成落难名士混进坞里（阿皎喂姜汤救活的就是他），腊月廿三从里面抽掉铁栓，放石雷、阎虎、封寒进来。
5. **她怎么活下来的**：石雷踹翻锻炉，红炭热灰泼了她一脸。阎虎问杀不杀，石雷嫌麻烦，说瞎了的丫头扔进雪里，冻一夜就死了。四个人回去复命：都烧干净了。
6. **四个人为什么散在天下**：刀到手以后，崔玄要灭知情人的口，一个个派人去杀这四个人。四个人各自逃命，投了乱世里不同的兵马（黄巾、洛阳的乱军、下邳的守军、乌林的水寨），崔府一时够不着他们。
7. **七年**：她听得出每一柄文家刀出鞘的声音。七年里她循着刀声找人，发现散在各路豪强手里的文家刀，都是从许都崔府送出去的。她以为崔玄只是买下这批赃刀的人，名单上的四个人只是动手的。
8. **序章他为什么不杀她**：她闯进崔府，说出「寒山坞文家」。崔玄一算年纪，伸手去碰她的蒙眼布：眉眼像她娘。他就知道了她是谁。不杀她有两层原因：
   - **算计**：那四个知情人他追了七年没杀干净，一个瞎了眼来报仇的女儿正好替他去杀。于是他告诉她「你连那四个人都没杀过」，把她扔出去。
   - **一点他自己都不肯认的不忍**：她的名字是他起的。
   第四关周默只说得出第一层。第二层留到第五关，由崔玄自己承认一半，让玩家自己判断。
9. **名字的扣**：「皎」是崔玄起的名字。第五关他叫她「阿皎」，她才知道连这个名字都是他给的。她当年从「皎」字里拿掉「交」、改叫刘白，到这时才算真正有了意义。

2. 雪夜独行 + 哨兵围上来（act-79 做的那段照旧，地点仍是去许都路上的残村）。打哨兵。
3. **崔府覆雪前庭**（借第五关场景）：她翻墙进府。廊下一个人在扫雪，是崔玄。他不叫人，听她说完「三十柄刀」，从身后的刀架上取下一柄文家刀。
4. **必败战**：打崔玄（第五关的头目，招式全开、序章她也全开）。打到她只剩两成血就剧情杀：他一刀挑飞她的刀，刀柄撞在她胸口。
5. 她单膝跪在雪里（act-77 的跪姿）。崔玄蹲下来，伸手要碰她的蒙眼布，又收回去。他对她说的意思是：「你连拿刀的那四个人都没杀过，就来找我。」让家奴把她扔出后门。**他没杀她**，这是留到第四关才解的扣。
6. 她扑倒在后门外的乱葬沟里（act-82 的趴姿）。
7. 天亮：杜五在城外收冻死的人、扒鞋，摸到她还有气，驮走（照旧）。
8. 破窑醒来，杜五、孙婆婆（照旧，台词改：她要回去的地方从「破庙」换成「崔府」，孙婆婆拦她）。

## 第一关 · 黄巾残村：石雷

- 战前（`ch1_before`）：第一次交手，不再是「你还活着」。石雷认出她手里的刀是文家的，想起那个风箱下的丫头，得意，吹嘘那一脚。
- 杀后（`ch1_after`）：热香炉灰按进他眼里（「热灰还眼」保留）。他求饶时吐出：阎虎在洛阳铸钱。还有一句扣子：「崔府那位放你出来的？……那他留你有用。」
- 回据点：断碑划掉石雷，刀架挂第一柄。

## 第二关 · 洛阳余烬：阎虎

- 地点：焚过的洛阳，阎虎在铸钱场把抢来的铜器熔成钱，也熔刀。
- 战前：他不认得她。她说出「高炉」，他想起来了，笑她娘「烧得旺」。
- 杀后：他临死说她娘不是铁匠的婆娘，是从崔府逃出来的乐伎，进坞时已经怀着孩子。她不信。他供出封寒在下邳。
- 拿回第二柄刀。

## 第三关 · 下邳寒沼：封寒

- 地点：水淹的下邳，封寒在药库里给守城的人看伤、也给人下毒。
- 战前：他摸她的脉，说她的脉象像一个人（不点名）。拿出装拇指的漆匣。
- 杀后：他告诉她：名单上四个人，事后都被崔府追杀过，只有他们逃散了。「你杀的每一个，都是他想灭口的。你在替他收账。」供出周默在乌林。
- 拿回第三柄刀。

## 第四关 · 乌林水寨：周默

- 地点：连环船火海。
- 战前：她听出他的声音，是那年冬天她一勺勺喂姜汤救活的人。这一场最重的是这件事，不是身世。
- 杀后（全剧的转折）：周默临死说破：崔玄是她亲爹；那夜的命令是「连那贱婢和野种一起烧」；崔府那天没杀她，是因为认出了她，留着她替他把这四个人清干净。
- 拿回第四柄刀。回据点，断碑只剩最下面那个名字。

- 战前：他承认，不辩解。他叫她「阿皎」。

## 结局（三选一，待用户定）

- **A. 杀了他，一个人走远**：她一刀了结，没有一句话。雪落下来盖住血（回到阿爹那句）。回破窑划掉最后一个名字，杜五在窑口等她，她没进去，往雪里走了。
