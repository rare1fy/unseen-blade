# 给 agy 的说明：《不见刀》剧本（对白）

你要为汉末三国题材的动作游戏《不见刀》重写全部对白。写完把成品**整份**写进同一个文件夹里的 `剧本.md`（`docs/对白/剧本.md`），格式严格照第 5 节——程序会按这个格式把台词读进游戏，格式不对的段落会被跳过。

## 1. 先读这些（都在本仓库里）

- `docs/STORY.md`：世界观、四个仇人、人物卡。注意文件开头的「11-17 改名」，以它为准；正文是旧稿，人名、姓氏以下面第 2 节为准。
- `CLAUDE.md` 第四节最后几条（act-23 起）：制作人对故事的要求和决定。
- `src/present/act/scripts.ts`、`src/present/act/hideoutLines.ts`：游戏里现在的台词。它们只是参照，可以全部推翻。

## 2. 定下来的事实（不能改）

- 主角对外叫**刘白**，本名**文皎**（小名阿皎），汝南深山铸刀铁坞「寒山坞」**文家**的女儿。文 + 刂 = 刘，皎 − 交 = 白：她割掉了名字里的「交」（与人的情分），给自己添了一把刀。
- 熹平六年腊月廿三（游戏开场的七年前），一个**下雪**的夜里，四个人血洗寒山坞。十一岁的她躲在铸坊的风箱底下，被拖出来，褚雷把滚烫的生石灰按进她眼里。她瞎了，头发也白了。
- 如今中平元年冬，她十八岁，白发、蒙眼、女扮男装，提着她爹打的环首刀，按一张名单找人：褚雷、阎虎、封鸩、周黯。
- 褚雷：当年按石灰的人，如今是黄巾渠帅，一根挂满铜环的引雷铁杖。他认得出文家刀脊上的锻纹。
- 杜五：收尸的，在战场边扒死人的鞋和铜钱过活，牵一头灰驴、拉一辆破板车；二十出头，嘴碎、土、心软，嘴上先装狠，左手少两根指头。他第一次救她是图她的刀和衣裳。她报名「刘白」以后，他叫她「白哥」。
- 孙媪：镇上的盲眼医婆，瞎了左眼，刻薄、利落、刀子嘴。杜五用扒来的两双死人鞋请她来接骨。
- 冯铁臂：哑巴老铁匠，右手齐腕断了、断腕上绑着一柄锤。他**不说话**，他的「台词」只写动作。他不在开篇出现，以后才来。
- 据点：一座废弃的烧瓦窑（破窑），窑外半截断碑，她用刀在碑上刻了四个名字。
- 每次她死在外面，都是杜五从死人堆里把她拖回破窑，孙媪把她救活。

## 4. 怎么写（制作人的要求）

- 这是个**悲凉**的故事，她是**孤独**的。读起来要像小说和戏，不像说明书：不交代设定、不解释规则、不报菜名地介绍人物；靠潜台词、动作、停顿、反问、没说完的话推进。
- 不要「抽象」的对白：不说空话、大道理、文绉绉的感慨。每句都是这个人在这个处境下会脱口说出的话，说的是具体的东西（刀、雪、鞋、骨头、药、钱、名字）。
- 她是个小人物：会疼、会怕、会输、力气不够，但咬着牙不退。恨要读得出来，但要冷、要狠，不喊口号，不直接说「我要报仇」。
- 雪是这个故事的母题：她的白发、那一夜、她听雪的方式、她的刀，可以自然地和雪连上，不要硬贴。
- 声口：刘白话极少、冷、每句都狠；杜五嘴碎、土、心软、爱骂人；孙媪刻薄利落、刀子嘴；褚雷傲慢粗野，带着「当年」的轻蔑；冯铁臂只有动作。
- 每句台词 22 字以内（要放进手机的对话框），大多 15 字以内。动作行 15 字以内。
- 汉末口吻，但别文绉绉；不要现代网络词，不要游戏术语。

## 5. 输出格式（严格照这个）

- 每段以 `## 编号` 开头（编号用第 3 节表里的，一字不差），后面可以空格跟一个中文说明。
- 段里每一行是一句：`- 说话人：台词`。说话人只能是：刘白、杜五、孙媪、冯铁臂、褚雷、字幕。
- 动作行：`- （动作）`，用中文全角括号，前面不写说话人。
- 随机池（death_*、npc_*、stele_none、stele_one）也一样，每条一行，写成说话人的一句。
- 文件里除了这些段落，别的都不要（不要开头的说明、不要分析、不要总结）。

示例：

```
## pro_fall 倒下
- 褚雷：……

## pro_wake 破窑醒来
- （刘白猛地惊醒，指尖抓空）
- 孙媪：……
- 刘白：……

## death_duwu 死了被拖回来·杜五
- 杜五：……
- 杜五：……
```
