# 给 agy 的说明：《不见刀》剧本（对白）

你要为汉末三国题材的动作游戏《不见刀》重写全部对白。成品**整份**输出，格式严格照第 5 节——程序会按这个格式把台词读进游戏，格式不对的段落会被跳过。

**11-17 第三稿**：上一稿制作人的意见是「缺乏情绪，大多数都太啰嗦了，而且像说明书」。这一稿最重要的就是第 4 节开头那几条硬规矩。

- `docs/STORY.md`：世界观、四个仇人、人物卡。注意文件开头的「11-17 改名」，以它为准；正文是旧稿，人名、姓氏以下面第 2 节为准。
- `CLAUDE.md` 第四节最后几条（act-23 起）：制作人对故事的要求和决定。
- `src/present/act/scripts.ts`、`src/present/act/hideoutLines.ts`：游戏里现在的台词。它们只是参照，可以全部推翻。

## 2. 定下来的事实（不能改）

- 主角对外叫**刘白**，本名**文皎**（小名阿皎），汝南深山铸刀铁坞「寒山坞」**文家**的女儿。文 + 刂 = 刘，皎 − 交 = 白：她割掉了名字里的「交」（与人的情分），给自己添了一把刀。
- 熹平六年腊月廿三（游戏开场的七年前），一个**下雪**的夜里，黄巾贼血洗寒山坞。开门引贼的是她亲手喂了三天热汤救活的洛阳名士——**周黯**。阿爹被一刀砍死。抢东西时贼兵**一脚踹翻锻炉**，烧红的炭和滚烫的炉灰泼了她一脸——**眼睛是这样意外烫瞎的（不是石灰，没有人按着她）**。阿爹临死说「雪把血盖住，人就看不见你了」。那一夜她头发全白了。
- 如今中平元年冬，她十八岁，白发、蒙眼、女扮男装，提着她爹打的环首刀，按一张名单找人：褚雷、阎虎、封鸩、周黯。
- 褚雷：当年带头的人之一（那夜狂笑的那个），如今是黄巾渠帅，一根挂满铜环的引雷铁杖，腰里挂着一柄抢来的文家刀。他认得出文家刀脊上的锻纹。她最后把滚烫的香炉灰按进他眼里，再一刀封喉（热灰还眼）。
- 杜五：收尸的，在战场边扒死人的鞋和铜钱过活，牵一头灰驴、拉一辆破板车；二十出头，嘴碎、土、心软，嘴上先装狠，左手少两根指头。他第一次救她是图她的刀和衣裳。她报名「刘白」以后，他叫她「白哥」。
- 孙媪：镇上的盲眼医婆，瞎了左眼，刻薄、利落、刀子嘴。杜五用扒来的两双死人鞋请她来接骨。
- 冯铁臂：哑巴老铁匠，右手齐腕断了、断腕上绑着一柄锤。他**不说话**，他的「台词」只写动作。他不在开篇出现，以后才来。
- 据点：一座废弃的烧瓦窑（破窑），窑外半截断碑，她用刀在碑上刻了四个名字。
- 每次她死在外面，都是杜五从死人堆里把她拖回破窑，孙媪把她救活。

## 4. 怎么写（制作人的要求）

**硬规矩（第三稿，最重要）：**

1. **短。** 大多数台词 **10 字以内**，最长 **16 字**。能三个字说完的不写八个字。一句只做一件事。
2. **少。** 每个场景的句数比上一稿砍掉三分之一以上。没有非说不可的话，就用一个动作行代替。
3. **不交代。** 不在嘴上讲地名、史实、谁投了谁、东西运到哪、来龙去脉、身世。玩家不需要被告知，他们会从后面的戏里慢慢拼起来。宁可让人有点没懂，也不要讲明白。
4. **情绪不写在字面上。** 不说「好重的血债」「我好恨」「太惨了」这类给情绪贴标签的话；情绪靠**动作行**（手、刀、呼吸、停顿）、没说完的话（……）、答非所问、反问、重复一个词。
5. 写每句之前先想：这个人**此刻最想要什么、最怕什么**？然后写他会**脱口而出**的那一句，而不是作者想让玩家知道的那一句。

**上一稿的毛病和改法（示例，照这个方向改全部）：**

| 上一稿（不要这样） | 毛病 | 往这个方向 |
|---|---|---|
| 左手这两根指头，是前年饥荒俺去抢发霉的麦饼叫人剁的。 | 啰嗦、讲身世 | （杜五把左手藏到背后）……抢饼，叫人剁的。 |
| 皇甫将军在长社放火破黄巾，百里麦田烧得寸草不生。 | 说明书、讲史实 | 那片麦子……烧了三天。 |
| 在洛阳！阎虎投了西凉董卓的飞熊军，刀全运进洛阳城了！ | 一口气交代剧情 | 洛、洛阳！阎虎……都在洛阳！ |
| 眼窝是滚炭烫烂的，青丝也是熬白的……好重的血债。 | 情绪贴标签 | （孙媪的手停在她眼上）……炭烫的。 |
| 官军跟黄巾贼杀红了眼，倒叫俺老杜捡了便宜。 | 交代背景 | 又是一地……啧，鞋都冻住了。 |

**其他（照旧）：**

- 这是个**悲凉**的故事，她是**孤独**的。像小说和戏，不像说明书。
- 说具体的东西（刀、雪、鞋、骨头、药、钱、名字），不说空话、大道理、文绉绉的感慨。
- 她是小人物：会疼、会怕、会输，咬着牙不退。恨要冷、要狠，不喊口号，不直接说「我要报仇」。
- 雪是母题，自然地连，不要硬贴。
- 声口：刘白话极少、冷、每句都狠；杜五嘴碎、土、心软、爱骂人（但这一稿他也要短）；孙媪刻薄利落、刀子嘴；褚雷傲慢粗野，输了就怂；冯铁臂只有动作。
- 动作行 12 字以内。汉末口吻，但别文绉绉；不要现代网络词，不要游戏术语。
- 开场字幕 pro_cold 固定为「阿爹说，雪把血盖住，人就看不见我了。」，照抄。

## 5. 输出格式（严格照这个）

- 每段以 `## 编号` 开头（编号用第 3 节表里的，一字不差），后面可以空格跟一个中文说明。
- 段里每一行是一句：`- 说话人：台词`。说话人只能是：刘白、杜五、孙媪、冯铁臂、褚雷、字幕。
- 动作行：`- （动作）`，用中文全角括号，前面不写说话人。
- 随机池（death_*、npc_*、stele_none、stele_one）也一样，每条一行，写成说话人的一句。
- 文件里除了这些段落，别的都不要（不要开头的说明、不要分析、不要总结）。

示例：

```
## pro_fall 倒下
- 褚雷：……

## pro_wake 破窑醒来
- （刘白猛地惊醒，指尖抓空）
- 孙媪：……
- 刘白：……

## death_duwu 死了被拖回来·杜五
- 杜五：……
- 杜五：……
```
