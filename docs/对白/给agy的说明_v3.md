## 2. 定下来的事实

- 主角对外叫**刘白**，本名**文皎**（小名阿皎）。白发、蒙眼、女扮男装，十八岁。杜五叫她「白哥」，当她是男人；孙婆婆知道她是女的。
- 眼睛是石雷**一脚踹翻锻炉**、红炭热灰泼脸**烫瞎**的。不是石灰，不是谁故意泼的。
- 人名：石雷（第一关，黄巾渠帅，铜环铁杖）、阎虎（第二关，洛阳，飞熊校尉，长柄大钺，在铸钱场熔铜）、封寒（第三关，下邳，截指鬼医，割过铁匠拇指，装在漆匣里）、周默（第四关，乌林水寨，那年开坞门的「洛阳名士」，她喂过他三天热汤）、崔玄（终局，许都崔府，司空长史，她的生父）。
- **不写年份**（不要「中平元年」「熹平六年」）。只说「那年」「七年前」「腊月廿三」。史实只当背景，不报谁投了谁。
- 刀：文家给崔府打了三十柄百辟刀。她每杀一个头目拿回一柄。游戏里刀是亮钢色，不要写「乌黑」「乌沉」。
- 据点是破窑，窑外半截断碑。新开局她在碑上刻**五个名字**：四个仇人一排，崔玄单独在最下面。

## 4. 写法（制作人反复要求过的）

- **像小说和戏，不像说明书。** 不交代设定，不替人物讲身世；身世靠仇人临死嘴里漏出来，她只听，不复述。
- 长短跟着情绪走：多数 6～16 字，最长 **24 字**。不要一刀切成电报，也不要啰嗦。
- 刘白话少、冷、硬，对仇人只说要紧的；知道真相后更少。杜五嘴碎、土，说的是眼前的事；孙婆婆刻薄利落；仇人各有各的腔：石雷狂到怂，阎虎粗野，封寒阴柔像大夫，周默斯文、说话带官腔，崔玄平静、不高声、像在谈家事。
- 雪是母题（白发、瞎、那一夜、雪盖住血）。
- 动作行写在括号里，一行一个动作，短，能拍得出来。
- 悲凉，主角孤独。复仇有代价：每杀一个，她并不更好受。

## 5. 输出格式（严格）

```
## ch2_before 洛阳·阎虎
- （动作行，写在中文括号里）
- 阎虎：台词
- 刘白：台词
```

- 每段 `## id 中文标题`，id 用第 3 节的。
- 台词行 `- 名字：台词`。名字只能用：刘白、杜五、孙婆婆、冯铁臂、石雷、阎虎、封寒、周默、崔玄、字幕。
- 动作行 `- （……）`。
- 不要加别的说明、注释、空段。整份写进 `docs/对白/剧本6.md`。
