# 不见刀 · 关卡设计方案（形态 + 小解谜）

> 用户 11-18：「这关卡形态确实严重雷同和不够。」（选了「每关一套专属形态」）「我是觉得关卡设计得可以再大点，结构丰富点，甚至可以加点小解密元素」
> 看了方案后定：六种小解谜都做；少数开路、多数可选；破庙也改。
> 再定：「我其实感觉现在随机地图的意义不是特别大，还不如都做成几种确定的造型，避免不稳定因素。」「毕竟要加入解密了」→ **地图不随机**。

## 一、现在的问题

- 第一关残村 / 麦田的 6 种屋形（方院、曲尺、回廊、窄巷、过桥、临水）都只是在一块长方形里挖一角、加一块、留一条巷、横一条河；**第二～五关所有屋子和头目间都是同一块两侧夹墙的长方院子**，只换了地面和两边布景。
- 根子在引擎：出口只能是左右两条固定高度的侧路 + 后面一条路，所以每种屋形都得在后面留一整条横带给出口，形状只能在前半块做文章。

## 二、总则

- **更大**：战斗屋长边 36～48 米（现在 21～35），头目场 30～40 米。
- **一间屋分区**，三种组织：
  - **单场**：一块大场地，靠地形（水、沟、高台边、柱子、碎石）把战斗切开；
  - **两段**：先打第一块，打完门洞开 / 吊桥落 / 闸门升，进第二块再打，出口在第二块；
  - **主场 + 侧院**：主场打仗，旁边藏着侧院 / 暗室 / 孤岛，里面是解谜和奖励。
- **只用横平竖直的大块**（不许斜线阶梯，切角最多一两级大台阶）；水、沟、熔坑打下去会死（照现在的规矩：敌人会掉、头目和她不会）；桥、跳板、门洞连各块。
- **出口开在任意边**（左、右、后，两段式的出口在第二块里），条数照旧 1～2 条。
- **每间屋都是定死的设计**（用户：「随机地图的意义不是特别大，还不如都做成几种确定的造型，避免不稳定因素」「毕竟要加入解密了」）：形状、掩体、可破坏物、机关、奖励、出口、布景每次进去都一模一样（布景用这间屋自己的固定种子，不再每次随机拼）；时段和天气也按屋子定。一局里还在变的只有「这一关走哪几间、出门选哪条路」。
- **一关的屋子**：3 间战斗屋（一局里每间最多进一次；死士间 = 其中一间换成更硬的敌人）、1 间头目场；行商 / 歇脚 / 遗卷用这一关的一个固定小院。第一关原来那五种随机屋形（曲尺、回廊、窄巷、过桥、临水）不再进轮换。
- **按区域刷怪**：她走进哪块区域，那块的敌人从那块的边上冒出来；两段式第一块清完才开第二块。
- 靠镜头一侧的墙做矮，不挡人。

## 三、小解谜（围绕「她看不见，靠听」）

每间屋最多一个；大约三成的屋子有。多数是**可选的**，解开给奖励（铜钱、回血、一张秘传或刀谱、局外货币）；少数用来**开路**（两段式的门），开路的一定有清楚的声纹提示，并且不会卡死（解不开就没法往前走的那种不做；开路的机关就在必经的路上、一碰就有反应）。

| 机关 | 怎么玩 | 提示（声纹） | 用在哪 |
|---|---|---|---|
| **听壁** | 一段墙是空心的，砍三下塌开，后面是暗室，里面有奖励 | 她走近时，那段墙的缝里一圈圈淡淡往外渗声纹；砍一下回一声空响 | 五关都有：残村的院墙、洛阳的殿墙、崔府的夹墙 |
| **铜铃** | 场边挂三只铃。进屋时远处传来三声回响，三只铃按顺序亮一下声纹；按同样的顺序砍铃，侧院门开；砍错，三只铃一起乱响、重来 | 回响时每只铃身上出一圈声纹，顺序就是答案 | 残村的祠堂、崔府的书房 |
| **断索** | 吊桥被一根绳拉在半空；砍断绳桩，桥落下，通到孤岛（奖励）或第二块区域（开路）。桥落下那一下砸到的敌人吃一记 | 绳子绷紧时嗡嗡响，绳桩出声纹 | 下邳的水巷、锁江的船之间 |
| **开闸** | 闸轮按住攻击 1 秒转动，一片水退下去，露出泡在水下的路（原来是坑，退水后变成地面） | 闸轮出声纹；水下的路隔一会儿冒一串气泡 | 下邳的城墙马道 |
| **火油开路** | 木栅挡着一条路；把火油坛打 / 踢过去撞上木栅，爆开烧掉，路通了（也能拿来炸敌人） | 木栅后面有风声，木栅出声纹 | 洛阳大街、锁江水寨 |
| **压板** | 门要压板上有东西才开：把敌人打飞到压板上（或者自己站上去，门开 5 秒，跑过去） | 压板咔哒一声、出声纹；门上的锁跟着响 | 洛阳宫道、崔府 |

奖励的规矩：一间屋的解谜奖励只拿一次；暗室和孤岛上的奖励用实物模型摆着（钱袋、药葫芦、竹简、残铁），走过去拿。

## 四、五关的屋形

图例：1 格 = 2 米。`#` 实地（房子、墙、殿基…填布景） `.` 地面 `~` 水 / 沟 / 熔坑（打下去会死） `=` 桥 / 跳板 `-` 吊桥（落下前是坑）
`D` 门洞（两段式先关着） `S` 起点 `E` 出口 `B` 头目 `o` 掩体（打不坏） `0` 大件掩体（大鼎、石碾） `j` 可破坏小件（陶罐 / 木箱 / 草垛，按地点） `t` 会倒的立柱 `!` 火油坛
解谜：`?` 空心墙 `b` 铜铃 `r` 绳桩（吊桥 `-`） `W` 闸轮 `w` 退水后露出的路 `X` 木栅（旁边的 `!` 是烧它的火油坛） `P` 压板 `$` 奖励

## 五、怎么做（用户：「关卡这个还是你来做吧，给codex我不放心」→ 我自己做，先出能玩的粗版）

1. **形态引擎**：屋形用上面这种字符图写（一格 2 米，换成地面格子），掩体、可破坏物、机关都照图上的标记摆，布景用每间屋自己的固定种子；出口按图上的 `E` 开在任意边；分区刷怪；连通检查（每块地面、每个出口、每个奖励都走得到，测试里所有屋形 × 多个种子都跑一遍）；头目间也走屋形；机关的通用框架（可被砍 / 被撞 / 被按的东西、声纹提示、开门 / 落桥 / 退水 / 塌墙的事件、奖励只拿一次）。
