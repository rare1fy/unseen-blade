# 动作原型 · 整体设计 v0.2（用户 11-16 已拍板五问，见第 9 节）

> 一句话：**哈迪斯那样的动作肉鸽**。一个蒙眼刀客，在三国乱世里一间屋一间屋地杀出去；死了回练武场，带回来的东西让下一局更强。
>
> 写于 2026-11-16。用户的要求：「规划一下别的设计了，招式、资源、成长什么的，朝专业的动作肉鸽游戏迈进」。
> 范围按用户之前的话控制：一个主角、一套核心机制，不堆数值系统（见 memory「My strengths / scope」）。

---

## 0. 玩家在做什么

**一局（约 25～35 分钟）：**

练武场 → 出门 → **地域一**（5～6 间屋 + 头目）→ **地域二** → **地域三** → 终局头目。

- 每间屋清完给一件奖励。路口立着木牌，牌上看得到下一间给什么（现在的高札就是这个），自己选走哪条。
- 死了回练武场，这一局的秘传和铜钱都没了，但带回「残页」，在练武场换永久成长。

**手上五个键（手机右下四颗 + 一颗大招）：**

| 键 | 现在已经有的 | 规划 |
|---|---|---|
| 斩 | 五段连斩、按住蓄力突进斩 | 刀谱换连斩手法（见 2.2） |
| 冲 | 冲刺、完美闪避 → 反击 | 不变 |
| 跳 | 跳、空中下劈、跳过低招 | 不变 |
| 技 | 影分身 | 改成**可换的招式槽**（见 2.1） |
| 绝 | —— | **新增：「一刀」**，杀意满后在完美闪避 / 见切时以 QTE 放出，不占按钮（见 9） |

## 1. 主角的核心机制：「听」

主角是瞎子，靠听声辨位。把这个设定做成玩法的核心，一条循环串起现在已经有的东西：

**听见出招 → 躲开或弹开 → 反击 → 攒杀意 → 一刀**

- **听见**：敌人出招前的地面预警，题材上就是「声音」。统一做成一圈圈「声纹」：劈砍是扇形波，扑咬是直线，砸地是圆环，箭是细线，能跳过的带横纹（现在已有）。这同时是用户说的「战斗信息传达」的统一语言。
- **杀意**：三格。完美闪避、砍飞一支箭、反击命中，各涨一格。挂在主角腰上三个小铃（3D 实物，满一格亮一个、响一声）。
- **绝·一刀**：杀意满三格可以放。时间一停，主角在画面里所有「听见」的敌人之间一道直线穿过，收刀，敌人一起倒——《目中无人》那种「一刀见血」。

为什么这样定：完美闪避、砍箭、反击这三样已经做了，玩家刚开始觉得爽；把它们串成「攒→放」，每一次躲和弹都有目标，打法自然从「乱按斩」变成「读、躲、反、放」。

## 2. 招式

### 2.1 「技」：可换的招式槽

开局在练武场从已解锁的招式里选一个带进局（局内秘传可以强化它）：

| 招式 | 按下去 | 用法 |
|---|---|---|
| 残影（现在的影分身） | 烟里两道分身斩开身边一圈 | 被围时解围 |
| 回风 | 刀脱手旋转飞出，绕一圈飞回来，来回都伤 | 打远处弓手 |
| 听雷 | 刀背顿地，一圈声波把周围敌人震退并「标记」，被标记的吃反击伤害加倍 | 配合反击 |

先做这三个，以后用残页解锁更多。

### 2.2 刀谱（相当于哈迪斯的武器形态）

**一把刀，三本刀谱**。刀谱在练武场用残页解锁，开局选一本。不同刀谱的连斩节奏和收尾完全不同，但五个键不变：

| 刀谱 | 连斩 | 特点 |
|---|---|---|
| 快刀 | 7 段，轻快，收尾连刺 | 输出稳，靠闪避 |
| 重刀 | 3 段，每刀更重，能打空头目架势 | 慢，靠时机 |
| 抽刀 | 平时刀在鞘里；按住蓄力，松开抽刀斩最强 | 一击，靠读招 |

现在的五段连斩就是「快刀」的雏形。

## 3. 资源

**局内**（一局结束就清零）：

| 资源 | 怎么来 | 用在哪 |
|---|---|---|
| 血 | 上限 100 起 | 回复间、少数秘传、商人回血 |
| 杀意 | 完美闪避 / 砍箭 / 反击 | 放「一刀」 |
| 铜钱 | 杀敌、奖励间 | 商人：买秘传、回血、磨刀 |

**局外**（带回练武场，只有两种，好记）：

| 资源 | 怎么来 | 用在哪 |
|---|---|---|
| 残页 | 每间屋少量，头目多 | 点心法、解锁刀谱和招式 |
| 信物 | 练武场里的江湖人送 | 一局带一件，各有一个特殊效果 |

## 4. 成长

### 4.1 局内：秘传（相当于哈迪斯的神恩）

- **来源**：江湖各派的传人。每派一个主题、一组秘传，改你的五个键。题材是三国乱世，先拟五派（名字和人物以后交 agy 细写）：
  - 太平道（雷：斩带雷，连锁跳电）
  - 五斗米道（符：中招的敌人身上贴符，过一会儿炸）
  - 江东水师（寒：减速、冻住）
  - 西凉骑卒（风：冲刺留风刃、冲得更远）
  - 益州锦官（火：燃烧、烧伤叠层）
- **每派 8～10 个**：一部分直接改某个键（「斩带雷」「冲留火痕」），一部分被动（「杀意多涨一格」「反击伤害 +50%」）。
- **合击**：同时拿了两派各一个特定秘传，会出现一个合击秘传（雷 + 寒 = 冰面导电）。
- **磨刀**：商人或奖励间的磨刀石，能把一个秘传升一级。

### 4.2 局外：练武场

- **心法图**：一张约 10 格的图，每格二选一（例：「多一次冲刺」或「冲刺无敌更长」），用残页点。相当于哈迪斯的夜之镜。
- **解锁**：刀谱、招式、新的秘传派别。
- **江湖人**：练武场里住几个人（铁匠、说书人、一位老师兄……），送信物、说剧情（台词交 agy）。
- **誓约**（通关后）：自己给下一局加难度条件（敌人更凶、没有回复间……），换更多残页。

## 5. 地域、敌人、头目

每个地域：6 种杂兵 + 精英变体 + 一个两阶段头目。屋子类型：战斗、精英、商人、回复（篝火 / 酒肆）、秘传、挑战（限时或无伤）。

| 地域 | 场景 | 杂兵（举例） | 头目 |
|---|---|---|---|
| 一 · 黄巾残村 | 乡野、麦田、破庙 | 黄巾力士、符水道士（远程诅咒）、流民（成群的弱敌）、弓手、猎犬 | 黄巾渠帅（雷法，两阶段） |
| 二 · 洛阳废都 | 宫殿废墟、烧焦的街 | 西凉铁骑（冲锋）、弩手（齐射）、刀盾兵（正面挡，要绕后或跳劈） | 西凉都尉（长戟） |
| 三 · 长江渡口 | 码头、船、芦苇 | 水寇、钩镰手（把你拉过去）、火船 | 锦帆贼首 |

现有的山贼、山犬、弓手、头目换成地域一的黄巾兵（造型重做成三国）。场景拼装器换一套三国素材。

## 6. 战斗信息传达（用户说的主要问题）

- **预警 = 声纹**（见 1），一种形状一种招，能跳的带横纹。
- **主角状态都在身上**：蓄力金环（已有）、反击金星（已有）、杀意三个腰铃（新）。
- **挨打从哪来**：主角脚下亮一段红色方向弧，指向打你的人（不加暗色遮罩）。
- **头目的大招**：出招前先吼一声、地面声纹更粗更亮，名字牌闪一下。

---

## 7. 不做的（控制范围）

- 不做多个主角、不做装备掉落刷数值、不做大型数值成长树。
- 秘传数值只分三档（普通 / 精良 / 传说），不做复杂公式。

## 8. 建议的开发顺序

| 阶段 | 内容 | 目的 |
|---|---|---|
| M1（下一步） | UI 风格定稿；杀意 + 「一刀」；声纹预警；方向弧 | 一间屋的手感和信息传达打磨到位 |
| M2 | 地域一完整：6 种黄巾杂兵、精英、渠帅；5～6 间屋；商人、回复间；两派秘传 | 一个完整的地域能玩 20 分钟 |

| M4 | 地域二、三，其余三派秘传，合击 | 一整局 |
| M5 | 剧情、江湖人、誓约 | 重玩 |

## 9. 用户的答复（11-16）

> 「①可以，甚至我想做居合那种招数，按住，看准时机出招霸体反弹。②可以③可以用，但是我觉得按钮有点多，绝可以不要是常显的，可以做点类QTE释放的设计。④可以⑤可以。」

1. **杀意 + 绝·一刀：定。** 另加 **居合 · 见切**：按住斩 = 收刀入鞘的居合架势（原来的蓄力），松手 = 抽刀斩。抽刀那一下正好接住敌人的攻击（攻击在松手后约 0.25 秒内打到身上）= **见切**：霸体不吃伤害不被打退，攻击被反弹（出手的敌人被震开、吃反弹伤害，箭原路射回去），抽刀斩伤害翻倍，涨一格杀意。
2. **技槽：定。**
3. **门派秘传：定。** 但按钮要少：**「绝」不做常驻按钮**——杀意满三格后，下一次完美闪避或见切时，时间几乎停住，斩钮外一圈金环往里缩，缩到钮上的那一刻按斩 = 放出「一刀」；没按中就放过，杀意留着等下次。手上始终只有四颗钮：斩、冲、跳、技。
4. **三个地域：定。**
5. **两种局外货币：定。**
