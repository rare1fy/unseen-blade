# 13 张刀客强化（act-36 规格：原定 12 张 + 用户要留的刀芒）

用户（act-27）：「精简到约12张」；（act-34 之后）：「三选一的强化怎么还是以前那种low low的ui，然后还是什么太平道啥的。。。」

原则：不分派、没有法术（雷、寒、火、风刃一律拿掉；飞出去的刀光是刀客的，保留），效果都落在刀上和身法上：刀口、血、骨、步法、拔刀、听声。每张三档（凡品 / 珍品 / 绝品），档位只改数值，不改玩法；磨刀照旧升一档。

| id | 名字（暂定，agy 定稿） | 效果（凡 / 珍 / 绝） |
|---|---|---|
| quick | 快刀 | 连环刀每一刀出得更快：出刀速度 +12% / +20% / +28%（只影响连环刀五刀，不影响藏锋、箭步斩） |
| extra | 多一刀 | 连环刀收尾一刀（k5）砍中后 0.12 秒，被它砍中的敌人再挨一道刀痕（不加新动作，只补一道斜刀光、火星和伤害）：收尾伤害的 40% / 60% / 80% |
| sunder | 破甲 | 被斩中的敌人 3 秒内受到的所有伤害 +12% / +20% / +30%（不叠层，再斩中刷新 3 秒）；精英、头目一样生效 |
| bone | 断骨 | 重招（收尾一刀 k5、箭步斩 rel、劈山 plunge、挑云 launch）斩中时，硬直多 0.3 / 0.45 / 0.6 秒，击退距离 +40%（更容易撞墙） |
| behead | 斩首 | 斩中时，若敌人剩余血量低于上限的 12% / 18% / 25%（精英减半：6% / 9% / 12.5%；头目和木人桩不算），直接斩杀，血量喷得比平时多一倍 |
| bleed | 放血 | 每次斩中给敌人叠一层出血（最多 5 层），每层每秒掉 1 / 1.5 / 2 点血；3 秒内没再被斩中就止血（层数清零）；出血的敌人每 0.4 秒往地上滴一小滴血（用 blood.ts 现有的血点） |
| drink | 饮血 | 每杀一个敌人回 3 / 5 / 7 点血（替换原来的 killHeal = 4） |
| frenzy | 惊血 | 自己血量低于上限一半时，所有斩击（不含飞镖）伤害 +20% / +35% / +50% |
| draw | 疾拔 | 藏锋蓄满用时 −30% / −45% / −60%；箭步斩（rel）伤害 +20% / +30% / +40% |
| counter | 回锋（暂名，避开招式名「破势」） | 破势成功（parry）后：那一刀伤害 +50% / +75% / +100%，并回 4 / 6 / 8 点血 |
| evade | 游身 | 完美闪避的判定时间 +40% / +70% / +100%；冲刺冷却 −15% / −25% / −35% |
| darts3 | 三才镖 | 甩镖一次三枚扇形（凡）/ 三枚且每枚伤害 +25%（珍）/ 五枚扇形（绝）；回身镖同样按这个数量 |
| bladeWind | 刀芒 | 连环刀收尾一刀（k5）放出一道薄月牙刀光，平着直线飞出（现有的 `BladeWave`，样子不改）：刀光伤害是现在的 100% / 150% / 200%，飞行距离 +0% / +20% / +40%（用户 act-35：「飞出去的刀光我想要，那个也是属于刀客的感觉」） |

拿掉：太平道 · 雷 8 张、江东水师 · 寒 8 张、燎原（火）、掠风（冲刺划刀）、寒刃（冻住）、借势、坚韧（加血上限，据点有成长）。刀芒保留（第 13 张）。

说明文字：每张两行，每行 ≤ 12 字，玩家语言（不写「k5」「判定」这类词）；数值写在说明里，用 `{v}` 占位（`vals: [凡, 珍, 绝]`，卡面按档位替换），例如「收尾一刀砍中后」「再补一刀{v}伤害」。
