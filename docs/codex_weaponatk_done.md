# 不见刀 · 敌人武器动作验收记录

八种敌人的十一招沿用实战的 `Action.at`。预览页和战斗通过同一套 `BattleActor` 姿势播放这些动作。分支为 `cx/weaponatk`，交付内容在工作树内。

## 逐招变化

| 敌人 | 招式 | 预览时看什么 |
| --- | --- | --- |
| 黄巾弓手 | `attack` | 弓始终在左手，走路和待机也随左手走。起手把弓举到肩前，右手把两段弦的交点拉到颊旁。命中时弦弹回、右手后撤，弓臂轻跳后放低。背上仍能看到箭囊。 |
| 黄巾力士 | `attack/slam` | 两拳握住短柄，锤头绕到右后方、高过头顶。胯先沉，锤头翻过额前，躯干折下。命中时锤头前缘触地，停一拍再提起。 |
| 黄巾力士 | `attack/sweep` | 身体向右拧，在右胯旁蓄锤。腰胸带动双手，让锤头在腰高经过正前方，惯性把锤带到左侧再收。 |
| 执矛水卒 | `attack/poke` | 右手把矛收到身侧，左手握住前段，矛尖平指前方。前脚先迈，双臂沿矛杆送出，随后抽回并抬起。 |
| 楼船弩士 | `attack/shoot` | 弩托贴近右肩，左手承托弩身。命中帧弦向前弹、模型上的弩矢离槽，弩身向肩头回跳，头部随之回弹后放低弩。 |
| 楼船弩士 | `cast` | `r45_ai.ts` 中射击后进入 2 秒装填等待，等待结束播放 0.30 秒的 `cast`。这段短动作里弩士屈膝、右脚踏出，弩前端压到脚边，左手扶弩，右手沿弩身把弦向上拉，起身时装回弩矢。 |
| 门下剑客 | `attack/poke` | 把剑尖放平，前脚短踏，剑臂伸直到胸前，左手向后平衡，再撤剑。 |
| 门下剑客 | `attack/lunge` | 前脚踏得更远，重心更低，身体俯前后把剑臂送直。短刺和扑刺命中时前踝分别在起点前方 0.36 和 0.51 米。 |
| 百辟刀卫 | `attack/cut` | 刀先收在右肩上方，命中时斜穿胸前，再向左下方带刀。侧面可看刀尖降高，战斗视角可看从右到左的轨迹。 |
| 执楯刀士 | `attack/lunge` | 左手把长楯立在身前，右手从盾的右缘向前平刺，命中时刀尖越过盾面，随后收回盾后。 |
| 凝霜毒吏 | `sow` | 选用向前顿杖。杆头带发光塞，能从举杖一直追到右前方的落点。左袖向外张开，杆头贴地停一拍后抬起。设计上侧面读落差，俯视读杖头伸出的距离。 |

## 三帧实测

每格依次为 **左右 / 高度 / 前后**，单位为米。左右和前后以当帧髋部为原点，正值分别朝角色自己的左侧和正前方。高度以地面为零。按预览页的模型原始比例测量。弓取握柄，锤取锤头中部，弩取弩身最前端面的中点，其他取可见刀尖、矛尖或发光杖尖。杖尖比模型声明的 `tip` 更长，因此直接读网格。

每个模型先转向 1.19 弧度并移离场景原点，按每秒 60 帧推进到精确采样时刻。设命中时间为 `T = dur × at`。蓄力取 `0.80 × T`，上弦取弩前端已落下的 `0.38 × T`。随动取 `T + min(0.12 秒, 剩余时长的一半)`。上弦行的中列是装填标记。

## 验证与待验

- `npx tsc --noEmit` 通过。
- 新增的武器测试 22/22 通过。完整套件 19 个文件、201/201 个测试通过，使用一个 Vitest worker。

## 验收（Claude，11-18）

在动作预览页暂停后逐帧看（每招六拍：命中前 30 % / 60 % / 85 %、命中、命中后 0.12 秒、收势），侧面和游戏镜头各一遍。十一招都用上了自己的兵器，读得出来。改了一处：

- **执楯刀士扑刺**：原来蓄力时刀一直竖着，命中前一瞬才突然放平；扑出时身子压得跟剑客的扑刺一样深，背把盾挡住，侧面和游戏镜头都看不见盾。改成蓄力时刀就放平、收在盾的右沿后面，命中时从盾沿刺出；他的上身前倾从 0.64 压到 0.24、胯下沉从 0.15 压到 0.10（`r45_pose.ts` `thrust`），人躲在盾后。测试 22/22 仍过。

预览页加了「暂停」和「下一帧」（一格 1/30 秒），截图用 `window.__animStep(秒)` 精确走到某一时刻、`window.__animLeft()` 归零后再拍。
