# 动作原型 设计记录

代码在 `src/present/act/`，分支 `act`。每轮用户反馈先记在这里和 `CLAUDE.md`，再动手。

## 方向（11-16 用户定）

- 玩法：哈迪斯式俯视角动作肉鸽，横屏手机操作，界面全是 3D 实物。
- **题材：三国乱世，主角是蒙眼刀客。** 用户：「日式题材我喜欢，但是不是很擅长，谢苗《目中无人》那个蒙眼大侠的感觉更合适我，背景放在三国乱世。」
  - 只借那种气质：冷峻、孤身、话少、一刀见血。造型、名字原创，不照搬电影角色和演员长相。
  - 汉末的视觉符号：环首刀（直刃单刃、柄尾一个圆环）、札甲（一排排小甲片）、交领右衽的短褐、宽腰带、绑腿、斗笠、蓑衣、幘（包头巾）。
  - 蒙眼布要在战斗镜头下一眼看得出：眼睛那一圈是一条凸出的布带，脑后打结，两条长布尾随动作飘。
  - 现在的场景和敌人还是日式的（竹山、山寺、山贼、山犬、弓手），等主角造型定了再换。
- 重点：用户说系统问题「都还好」，**主要问题在战斗信息的传达，以及战斗、动作、特效的表现**。

## 第二轮要做的（act-02）

1. **手感参数**：用户调好的数值写回默认值（跟手 42、顿帧 1.4、震屏 2、镜头高 11.6 / 后退 16.4 / 视角 45、前引 0.6）。前引改成最多按跑速算，冲刺时镜头不再往前猛涌，跑动时的感觉和用户调的一样。
2. **木桩关（练武场）**：打开游戏先到这里，边打边调参数。
   - 三个木人桩：挨打会晃、出伤害数字、不会死。
   - 地上几块召唤石板（山贼 / 山犬 / 弓手 / 头目）：踩上去叫出一个来陪练，是真的敌人。
   - 练武场里主角不会死，血打空了自动回满。
   - 一侧站着几个主角造型，走过去就换成那个造型。
   - 后面有「出发」的路口，走进去开始三间屋的正式一局；死了或打完回到练武场。
3. **弹箭**：刀砍到飞来的箭，箭被随机弹飞：方向在出刀朝向左右 75° 里随机，附近正好有敌人就偏过去一点，让「砍回去打中人」常常发生。弹飞的箭更快、打着转、拖一道金光，能打中敌人（伤害约是射你那一下的两倍，带硬直）。砍中那一下要有顿帧、闪光和短暂慢放，这是高光操作。
4. **跳跃**：
   - 键位：电脑空格；手柄 A（攻击改到 X）；手机加第四颗石钮「跳」。冲刺改成 K / Shift。
   - 起跳高约 1.3 米，滞空约 0.55 秒，空中可以转向。
   - 空中按斩是**下劈**：在空中顿一下，猛砸下去，落地一圈冲击，伤害比普通斩高、顿帧重。
   - 空中能冲刺。
   - **能跳过的攻击**：山犬的扑咬、头目的砸地。这两种的地面预警加白色横纹，一看就知道能跳；劈砍和箭跳不过去。
   - 落地有尘土和一下下蹲，脚下有一团影子标出落点。
5. **奔跑**：满速时身体前倾、大步幅、高抬腿、手臂摆动、有腾空的起伏，步频跟速度对上；慢推摇杆还是走。跑起来脚下带一点尘土。
6. **主角造型**：四个三国蒙眼刀客，放在练武场里换着看，另出一张站排图。

## 第三轮（act-03，用户看完 act-02 后）

用户原话：「我感觉带斗笠那个还不错，但是我想再多看几种造型，更酷、更潇洒的。然后现在奔跑的动作左摇右晃的，不帅，还有就是现在挥刀的时候，往前位移的程度不够，做成可调试参数。还有就是，普通攻击我希望能再多几段，3段太单调了。主角也有点太胖了，做一个女性版出来，蓝眼武士那种设定的三国版。」女主角追问后：「我只是想让你参考那个人物，不是要复刻别人也是蓝眼睛，我们就做瞎子。」连斩段数选 5 段。

1. **身材**：新造型全部改瘦改长：肩宽从 16 格收到 12 格，腿 2 格宽、长 11 格，头 6 格宽 7 格高。女主角再窄一点、矮一点。动作按每个模型自己的腿长算胯高，脚不悬空不陷地。
2. **待机更潇洒**：蒙眼刀客站直，重心在后脚，刀尖斜指地面，左手背在身后，偶尔侧头听声。
3. **新造型**（都是瞎子、都拿环首刀）：
   - 男：斗笠（瘦版，用户说还不错的那个）、大氅（齐小腿的黑大氅、红里子）、白发（白色高马尾、单袖）、帷帽（宽檐帽四周垂下黑纱）。
   - 女：两个，借《蓝眼武士》主角的气质（冷、狠、利落、孤身），不照搬造型：马尾（高马尾、窄袖劲装、红腰带）和短发（齐耳短发、男装、斗篷）。
   - 练武场后排木台换成这些新造型，旧的斗笠留一个对比胖瘦。
   - 用户补充：「衣服不要那么长，还是要干练一点的，头上保留长飘带」→ 所有下摆收到膝盖以上，「大氅」改成只到大腿的短披风；每个人头上两条长飘带（蒙眼布尾，马尾那个从发带垂下来）。
4. **奔跑**：上身稳住，去掉扭腰摆头，左手少摆，只留步子和起伏。
5. **出刀前冲**：变成面板参数：每一刀往前冲多远（米），以及冲到离目标多近停下（贴身不穿过去）。每段在这个基础上有自己的倍数。
7. **蓄力指示**（用户补充：「蓄力的时候我们自己的状态上也要有指示才行」）：脚下一圈金色进度环随蓄力长满，刀尖冒金星（越满越密）；蓄满那一下环外再亮一圈、人闪一下白、叮一声；右下「斩」钮从下往上灌金色，满了金边一直微微亮。
6. **五段连斩**：横斩 → 反手撩斩 → 回身旋斩（打一圈）→ 连刺两下（更远、更窄）→ 跃起重劈（重击收尾）。原来「第三刀」触发的秘传改成「收尾一刀」。

## 第四轮（act-04，用户看完 act-03 后）

用户原话：「现在的肩膀都好怂起来，然后攻击动作有点太快了。」

1. **肩膀**：瘦版的头直接坐在胸口顶上，没有脖子，肩线和下巴平齐，看着像一直耸着肩。改成：加两格脖子（头抬高），躯干短一格（总身高只多一格）；披风和短发的护肩原来叠在肩膀上方，改成长在手臂上、和肩线平齐。
2. **出刀速度**：五段每一刀的时长都放慢约四分之一（横斩 0.34 → 0.42 秒，反撩 0.36 → 0.45，旋斩 0.44 → 0.55，连刺 0.42 → 0.52，重劈 0.6 → 0.74），连段节奏跟着放慢。面板「出刀速度」还能再整体调。

## 第五轮（act-05，用户看完 act-04 后）

用户原话：「刺击的动作完全没表现出来，看起来就是刀剑抖了两下。攻击的动作频率还是有点太高了。」

1. **连刺重做**（第四刀，0.8 秒）：
   - 蓄：右肩往后拧，刀收到腰侧、刀尖朝前，膝盖下沉，身子往后坐一点。
   - 第一刺：左脚弓步踏出，右腿蹬直，手臂整条伸直，刀尖直指前方，人往前扑；刀尖前方拉出一道约 1.5 米的白色直线刺光，尽头一小簇火花。
   - 半收：手臂收回一半，身子不退。
   - 第二刺：扑得更远，刺光更长更亮，刺完停住一拍再收。
   - 出刀前冲分成两段，每一刺各冲一半。判定改成更窄更长（一条线）。
2. **出刀频率**：原来下一刀在上一刀命中后 0.12 个动作就能接上，收招几乎被砍光，连按时一秒能出三四刀。改成每一刀做完约 75% 才接下一刀（面板「连段衔接」0.4～1 可调），每刀时长再加长一点：横斩 0.46、反撩 0.48、旋斩 0.6、连刺 0.8、重劈 0.8 秒。整套五刀从约 1.4 秒变成约 2.6 秒。

## 第六轮（act-06，用户看完 act-05 后）

用户原话：「我感觉现在人物的肩膀和手臂的衔接还是有点问题的样子，感觉可以再近一点点，然后我感觉现在这个2x的效果是最好的。另外，现在的idle动作有点太看不出在待机了，另外，玩家的攻击动作没持刀那只手太僵硬了。」

1. **肩臂衔接**：手臂整体往里收一格，和胸口最外一列重叠，抬手、甩手时肩膀下面不再露出缝；胸口顶那一行保持满宽，盖在手臂内侧顶上，像一块肩头。上一轮为了「不耸肩」删掉的手臂顶一行补回来（胸口顶已经补齐，不会再高出肩线）。女主角也一样，肩宽和男的一样，靠头发、腰封和胯区分。
2. **像素 2x**：动作原型默认 2x 像素（电脑上）。手机上保持 1x（骰子版时用户说过「2x还是太不清晰了在手机上」）。`]` / `[` 键调大小，P 键开关；网址加 `px1` / `px2` / `px3` 指定。
3. **待机看得出在待机**：呼吸加大（胸口起伏、肩一抬一落），重心在两只脚之间慢慢换，刀尖慢慢画小圈，头隔一会侧一下听声；每隔约 5 秒挽一个刀花（手腕翻刀一圈再收回指地）。布尾飘动加大一点。
4. **空手不僵**：五段连斩每一刀都给左手配动作——横斩时左手先护在胸前、出刀时往后甩开；反撩时左手跟着往前推出一掌；旋斩时左臂张开跟着转；连刺时往后甩（已有）；跃起重劈时左手先上举、落刀时往下压。

## 第七轮（act-07，用户看完 act-06 后）

用户原话：「idle不要做那个转刀，看起来像个bug。然后现在左手的动作还是不自然，少了些小臂的弯折，手就老是一直直着，所以感觉很僵硬，你去往上看看中式的动作游戏的战斗动作是怎么做的。」

**查到的（网上关于游戏里左手动画的直接资料很少，能用的是武术和武打设计的说法）：**
- 太极刀的资料说，用刀时空手通常张开，随时准备抓、推、打，有些动作里还给持刀的手臂做配重；用空手去控制对方持兵器的手臂，刀比剑用得多（taichiunion.com 的《Secrets of the Sword》）。
- 武打设计的讨论强调动作要「好看又合理」，中国武术尤其讲究招式的先后次序（polycount 论坛《the logic of fight scene design》）。
- 《影之刃零》用动捕拍武术老师，再由动画师夸张处理（B 站访谈）。
- 加上刀术本身的老规矩：「单刀看手」——单刀好不好看，看的就是空着的那只手。常见手形是立掌（掌心朝前、手腕上翘），位置在胸前、右肩前、右腕旁或举过头顶；收势时收到腰间。手臂走弧线，肘始终带弯，只有推掌打到尽头那一下才接近伸直。

**这一轮的做法：**
1. 待机去掉转刀。保留呼吸、换重心、刀尖小圈。
2. 左手的规则：任何时候肘都弯着（小臂和大臂至少约 60°），推掌到底也留一点弯；手腕跟着动作翻（立掌朝上 / 收手朝下）。
3. 各动作的左手：
   - 待机：左手收在腰间，肘向外、小臂横在腰前。
   - 跑：小臂弯成直角贴身，小幅摆。
   - 横斩：蓄力时左手立掌护到右肩前，出刀时随身体拧回、收到左腰，肘弯着。
   - 反撩：先往侧上方亮掌（肘弯），刀撩过去后推出一掌，手腕立起。
   - 旋斩：左臂弯成直角架在胸前，跟着身子转。
   - 连刺：蓄力时左手立掌护在胸前，刺出时左手往头侧上方亮掌（弓步刺的常见架子）。
   - 跃起重劈：左手跟着右手一起举、一起落，像双手压刀。
   - 蓄力 / 突进斩：蓄时左手立掌在胸前，突进时往后上方亮掌。
   - 跳、下劈、冲刺、落地：都改成弯肘。

## 第八轮（act-08，用户看完 act-07 后）

用户原话：「砍箭的反馈窗口太短了，很难操作出来，然后闪避成功的时候也应该要有很强的反馈和奖励。」

1. **砍箭窗口**：原来只在刀命中的那一帧检查箭，等于一帧窗口。改成：每一刀从命中前 0.1 秒开始，刀「挡箭」持续一段时间（面板「砍箭窗口」，默认 0.35 秒），这段时间里飞进身前半圈、刀够得着的箭都会被弹飞；挡箭范围比砍人宽。按斩时如果 4.5 米内有箭正朝自己飞，先转身朝箭出刀（比朝敌人优先）。
2. **完美闪避**：冲刺的无敌时间里躲过一记本来会打中的攻击（劈砍、扑咬、砸地、箭），或者跳过山犬扑咬 / 头目砸地 = 完美闪避。0.8 秒内只算一次。
   - 反馈：慢放约 0.45 秒；脚下一圈冷蓝光环扩散，身边留三道残影，人闪一下冷光；头顶蹦一个「闪」字；「叮」一声 + 风声；手机震一下。
   - 奖励「反击」：2 秒内下一刀伤害翻倍、必定打出硬直（头目算重击，扣架势更多），这一刀刀光变金、命中时金色爆点和更重的顿帧；冲刺冷却立刻转好，影分身冷却减 1.5 秒。反击可用期间刀尖冒金星，右下「斩」钮金边一直亮。
   - 面板可调：闪避慢放时长、反击持续时间、反击伤害倍数。

## 第九轮（act-09，用户看完 act-08 后）

用户原话：「我感觉现在的角色都有点没有踩在地上，人物上面我最终决定最好的还是男版，接下来解决下ui的问题吧，移动的摇杆不要满屏幕都可以响应和拖着跑，然后现在的UI欠缺了题材的风格化。与之配套的，我觉得要规划一下别的设计了，招式、资源、成长什么的，朝专业的动作肉鸽游戏迈进」；追问后：「都做给我看看样式，然后主角是斗笠版」。

1. **踩实地面**：太阳的影子斜着落到一边，脚底下没有暗的东西，看着像飘。每个角色脚下加一团软的接触阴影（主角跳起时缩小变淡，兼做落点），木台上的造型也有；脚和小腿始终投影子。
2. **主角**：默认斗笠（瘦版）。
3. **摇杆**：只有左下一块（屏宽 42% 以内、屏高 38% 以下）按下才出；出在按下的位置，之后底座不动，手指拖出去只是推满。面板「摇杆」= 1 时固定在左下角，只有按在它附近才响应。
4. **三种 UI 风格**（`act/skin.ts`，U 键 / 调参面板 / 网址 `ui=` 切换，记在浏览器里）：
   - 汉代漆器：八角黑漆盘、金色分段纹、朱漆心、金字；血量是黑漆长匣里一道朱红、两头金扣；横幅黑漆描金、四角朱红。
   - 竹简木牌：竹片拼的方牌、两道麻绳、正中朱砂印刻字（阴文）、顶上挂绳；血量是十片竹简，掉血一片片暗下去、沉下去；横幅是竹简、右端小红印。
   - 兵戈铁器：黑铁八角盾、一圈铜钉、铜色刻字；血量是十片札甲（红甲绳），掉血一片片变黑掉下；横幅铁板四角铜钉。
   - 技能钮上直接刻字：斩 / 冲 / 跳 / 影。秘传卡、敌人血条也跟着换色。
5. **整体设计**：写在 `docs/GAME_PLAN.md`（草案，待用户拍板）。

## 第十轮（act-10，用户看完 act-09 后）

用户原话：「UI风格我比较喜欢铁那一套，但是我感觉做得还不够好，有点单调，然后按钮上不要摆文字。血条也很抽象。」以及对设计五问的答复（见 GAME_PLAN.md 第 9 节）。

1. **铁器界面重做（默认）**：
   - 按钮不放字，刻图形：斩 = 竖着的环首刀；冲 = 一只脚印带三道风线；跳 = 两层向上的折角；技（残影）= 三个错开的人影。
   - 不再单调：钮是有层次的铁盾——外圈一片片凸起的甲片、甲片间铜钉、中间一块铜心；斩钮下面垂一条红布穗，会晃；转好时外圈泛起炉火般的橙光，蓄力时甲片从下往上烧红。
   - 摇杆：铁环底座一圈甲片，摇杆头是一个环首刀的铜环。
   - 血条一眼看懂：左边一个圆铁框，里面是主角头像（斗笠、白蒙眼）；右边一条铁槽，里面是红色血，掉血时有白闪和拖尾，每 10 点一道刻痕；数字在槽尾。血条下面三颗铜锭是杀意，满一格烧亮一颗。

## 第十八轮（act-18，用户在 iPhone · Safari 上玩 act-17 后）

用户原话：「我试了下，不还是没震动吗？我觉得combo在按钮上要有点动特效提示，不然根本不知道怎么打。另外，我想知道为啥手机上看2x像素又太糊了，可以让我在电脑端和手机端看起来像素感一致吗」。追问：iPhone 的 Safari，面板上写着「iOS 18 才支持」。

2. **招式联动提示**：能接招的那一刻，对应按钮的一圈甲片换成那一招的颜色并呼吸发亮，按钮左上方弹出一个小图标（像素图，不放字），接完或过了时机就收回：
   - 冲刺中：斩钮「穿风斩」（青白，一道带风线的横斩）、镖钮「回身镖」（米白，往回的箭头带镖）；
   - 空中：斩钮「下劈」（金色，向下的箭头）、还能二段跳时跳钮「二段跳」（淡蓝，两道上折）；
   - 镖插在敌人身上：斩钮「追影」（靛色，带影线的镖）；
   - 完美闪避后的反击时间：斩钮「反击」（金色，交叉的两刀）；
   - 入鞘时攻击快打到：原来的白色「现在松手」不变。
   同一颗按钮同时有几个时，按 追影 > 穿风斩 > 下劈 > 反击 的顺序只显示一个。
3. **像素感一致**：
   - 原因：像素大小一直是按「几个 CSS 像素一格」算的。电脑全屏约 900～950 个 CSS 像素高，2x 有 450 行以上；手机横屏只有约 390 个 CSS 像素高，2x 只剩约 195 行，格子粗了一倍多。另外画布最多按 2 倍屏渲染，iPhone 是 3 倍屏，浏览器把画面再放大 1.5 倍并做了平滑，像素边缘发虚。
   - 改法：像素大小按屏幕高度算——2x = 画面约 450 行（3x 约 300 行，1x 约 900 行），在高分屏（手机、2 倍屏笔记本）上都按这个行数；普通 1 倍屏电脑保持现在的整数倍不变（1280×720 到 1920×1080 的窗口看起来和以前一样）。像素模式下画布最多按 3 倍屏渲染，手机不再被浏览器二次放大。
   - 代价：手机上的场景像素比原来 2x 多（约 450 行，比原来 1x 的 390 行还多一点），帧率可能比原来 2x 低；不够快就在面板切 3x（约 300 行）。

### 挥砍的身形：查到的资料和结论（11-17）

查到的说法（练法各家有出入，取共同的部分）：
- 户山流拔刀道（日本，试斩为主的流派）：出刀时约 70% 体重在前腿，前膝弯，后腿伸直但不锁死。见 toyamaryu.org 的 kamae / draw stance 两页。
- Academie Duello（加拿大的欧洲 / 意大利剑术学校）《Swordplay from the Ground: Cutting Mechanics & Timing》：肩、肘发力的劈砍都要靠胯和躯干的转动——胯先转、肩和手臂跟着把刀送出去；刀落下的那一刻正是前脚踩实的那一刻；身体先于刀动是常见错误。
- 天心流「釣瓶落」：竖劈时上身前倾到背几乎与地面平行，背是直的、不弓。另一份居合资料：劈砍过程中胯的高度保持不变、膝微屈；胯往前送，不往后坐（往后坐会泄力）。
- 中国武术弓步（陈泮岭《中华国术教材全集》）：前腿屈膝（膝不过脚尖）、后腿蹬直、扣膝裹裆，顶头竖项、沉肩坠肘；刀术讲以腰带劲、身随刀走。
- 军刀击剑的弓步研究：前冲的力量来自后腿蹬出，带动胸廓的转动。

结论（游戏里的做法，俯视镜头下要读得出来，所以比真人再夸张一点）：
- 出刀全程胯沉下去、不起伏：两膝始终屈（前膝 1.0 以上），出刀那一下前腿深弓（约 1.3）、后腿蹬直（约 0.2）。
- 上身前倾：起势约 0.32、出刀那一下 0.6～0.66 弧度（约 35°～38°），背是直的；头往回抬（顶头竖项），不看地面。
- 重心往前送：出刀那一下胯往前移约 8 厘米、压在前脚上；出刀的那一帧和前脚踩实同时。
- 胯先转、胸跟、臂最后（act-26 已做），加上面这些，连环刀前两刀、旋斩、连刺、跃劈都改；待机仍是站直听声（只改出刀）。

### 手柄、改键、暂停菜单（11-17）

用户先问「为啥我现在的技术栈上不了主机游戏？」，接着：「帮我把手柄的按键映射和手柄支持做了吧。」问后选：默认键位用现在这套、逐键改键、暂停菜单一次做成 3D 铁器风格。

查下来的现状：战斗里手柄能用（左摇杆、X 斩、A 跳、B / RB 冲刺、Y 镖），开始画面能用十字键 / 摇杆选、A 确认、B 返回；但秘传 / 刀谱三选一、立绘对话、演出跳过、旧开场「点一下」、设置（网页调参面板）都只认键鼠，用手柄打到第一次三选一就卡住；十字键不能走；摇杆轻推直接两成速度；PS / Switch 手柄上也显示 Xbox 字母；手柄不震；没有暂停；只认第一个连上的手柄；三选一一弹出按键就生效，打怪时连按会误选。

做法：

- **键位**（默认）：X 斩、A 跳、B 冲刺、Y 远程；RB、RT 也是冲刺；左摇杆 / 十字键走（十字键八方向）；按住远程瞄准时右摇杆指方向（没推右摇杆就用左摇杆）；Start 暂停。键盘照旧：WASD / 方向键走，J 斩，空格跳，K / Shift 冲刺，L / E 远程，Esc 暂停。
- **摇杆**：圆形死区 0.2，死区外重新映射成 0～1（轻推慢走，推满跑），不再一过死区就是两成速度。
- **改键**：暂停菜单「键位」一页，攻击 / 闪避 / 跳跃 / 远程四行，每行写键盘键和手柄键（手柄画成按钮图形）。选中一行按确认 → 这一行等新按键（约 5 秒），按键盘就改键盘、按手柄就改手柄；新键原来归别的动作的，两个对调；走路键（WASD、方向键、十字键）、暂停键（Esc、Start）、Select 不能绑；最后一行「恢复默认」。记在本机（`ub.bind`）。冲刺的备用键（Shift、RB、RT）和远程的 E 不显示，被别的动作占了就让出去。
- **菜单操作**（不随改键变）：手柄 A 确认、B 返回，十字键 / 左摇杆选（按住会连跳）；键盘回车 / 空格 / J 确认、Esc 返回。三选一：上下选（卡片是竖排的），弹出后 0.4 秒内不收键，而且要松开再按才算，打怪连按不会误选；立绘对话：A 或 X 翻页；演出：按住 B 约 0.8 秒跳过（右下那圈照样长满）；旧开场「点一下」：手柄任意键。
- **暂停**：Start / Esc 打开；手柄断开、切到别的窗口 / 后台时自动打开。世界、敌人、粒子、计时全停（引擎每帧的游戏时间给 0），音乐照放。开始画面、开场、演出播放中不弹暂停（演出用按住跳过）；三选一开着时也不弹。关掉暂停后，之前按着的键要先松开才重新算按下（不会一关菜单就跳一下）。
- **暂停菜单的样子**：和开始画面同一套铁框漆面牌匾（铜端帽、铆钉），从左边一块块滑进来，选中的往前凸、发暖光，旁边一把环首刀柄指着（开始画面那把）。不压暗画面（用户的规矩：不加暗色遮罩），只把世界停住。第一页：继续 / 键位 / 设置 / 回据点（只在出门打的时候有，要再确认一次，算这一趟战死）。「设置」页把调参面板里给玩家的那几项搬进来（界面风格、正文字体、震动、试一下震动、开始画面、造型、像素），每行一块牌匾，确认就换到下一个值；调参面板本身留着给调手感用。开始画面的「设置」也打开这一页。手机：鼠标 / 手指点牌匾也能用。
- **按键提示**：认手柄型号——名字里带 054c / DualSense / DualShock / Wireless Controller 的按 PlayStation（✕ ○ □ △、L1 R1 L2 R2），带 057e / Nintendo / Pro Controller / Joy-Con 的按 Switch（B A Y X、L R ZL ZR，位置照浏览器的标准排布：下 = B、右 = A），其余按 Xbox（A B X Y、LB RB LT RT）。按钮图形是像素画的小圆钮（Xbox 彩色字母、PS 深底彩色符号、Switch 深底白字母），肩键 / 扳机是圆角小方块写字母。技能钮下面的说明：用手柄时写「攻击」+ 对应按钮图形；键盘时照旧写键名；都跟着改键走。第一次进房的提示横幅、据点「走近人按 J 说话」也按设备和键位写。
- **震动**：用手柄时震手柄（Chrome / Edge 的 dual-rumble）：轻 = 砍中、中 = 重击 / 完美闪避 / 破势、重 = 挨打 / 不见刀，力度和时长分三档；走同一个「震动」开关。别的浏览器不支持就不震。
- **多个手柄**：哪个手柄最后有输入就用哪个。

   - 冲刺类（穿风斩、回身镖、穿心腿）：冲刺中 + 冲刺在地上结束后 0.3 秒（`TUNE.linkDash`）。连斩里冲出来的那一下，冲刺途中按斩 = 穿风斩，停下后按斩 = 游身斩（两招不抢）。
   - 砍中类（挑云、迎面镖）：每一刀的出刀那一下起 0.5 秒内（`TUNE.linkCut`），下一刀已经开始了也算（连按斩也接得上）。
   - 游身斩：冲刺后 0.45 → 0.6 秒（`TUNE.linkKeep`）；寻声 1.2 → 2 秒；扫八方、回锋斩不动。
   - 跳、镖的按键缓冲 0.12 / 0.15 → 0.2 秒，出刀前一点按也算。
2. **新资源「气」**（代码里叫 qi；玩家看到的叫法 agy 起），三格，打法 = 连招和派生攒气 → 花气藏锋拔刀 / 破势 → 攒杀气 → 不见刀。
   - 攒（每次出刀至少砍中一个才算）：连环刀一、二、三刀各 0.15 格，连刺每刺 0.1，收尾 0.25（一整套约 0.9 格）；刀谱派生（挑云、迎面镖、回身镖、游身斩、扫八方、穿心腿、寻声那一刀；镖类按一把镖的第一枚命中算一次）0.3；穿风斩是开局就有的，按普通一刀 0.15 算（不然冲刺斩连发成了新的无脑）；劈山 0.2；完美闪避 0.5；砍飞一支箭 0.25。调参「攒气倍率」。
   - 花：只有藏锋拔刀，一次一格（箭步斩、破势都算，破势成功不返还）；在拔刀（松手）那一刻扣。藏锋里冲刺取消、挨打打断不扣。
   - 不够一格时长按斩进不了藏锋：按钮摇头、钮圈闪暗红（同冷却中硬按），松手也不砍。
   - **屏息**：蓄满后最多再撑 1.2 秒（`TUNE.stanceHold`），最后 0.4 秒脚下金环抖、变暗；到头她吐一口白气收势，这一格气白花。
   - 每间屋开场至少一格（多的带进下一间）；试剑坪里气自己回满（练破势不用先攒）。
3. **「现在松手」的白光保留**（用户选的；限制靠气和屏息）。
4. **斩钮上方三颗灯**：和镖钮的三颗铜灯一个做法，攒到一半的那颗半亮；藏锋时要花的那颗灯闪；扣掉时灭一下。
   - 灯的样子：每颗是一个暗色灯座，里面的亮芯按这一格攒了多少从下往上长（半格 = 半亮），淡青白色（和镖钮的铜灯、杀气的铜锭分开）；灯在斩钮右上肩，不压「远程」两个字。
   - 实测（act-38 + 本改动，开发服务器）：1 格时松手拔刀 → 0 格；0.5 格长按 → 不进藏锋、钮摇头、灯闪暗红、松手不砍；2 格按住不放 → 约 2.1 秒吐气收势、剩 1 格、之后松手不出刀；冲刺停下 0.08 秒后按斩 → 穿风斩；第一刀收完 0.1 秒后按跳 → 挑云、按镖 → 迎面镖（三枚、一把镖）；一整套连环刀砍木人桩约 0.9～1 格。
5. **教学慢放**：刀谱派生（寻声、回身镖、迎面镖、挑云、穿心腿、游身斩、扫八方；二段跳不算）在本机前三次能接的时候，时间放慢一半约 0.6 秒，按钮翻面换色照旧；试剑坪不慢放。次数记在本机 `ub.taught`。
