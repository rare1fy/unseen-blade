# 自己改模型（MagicaVoxel）

这里的 `.vox` 是游戏里的模型。用 MagicaVoxel 打开、改、存盘，游戏就用你改的。

| 文件 | 是谁 |
|---|---|
| `fine_white.vox` | **主角姜烬 · 白发（游戏里默认用的）**，细格子：一格 3.5 厘米，人约 58 格高 |
| `fine_hat.vox` | 主角姜烬 · 斗笠（「设置」里切换），细格子 |
| `slim_white.vox` / `slim_hat.vox` | 7 厘米的旧版（一格 7 厘米，人约 28 格高），游戏里已经不用，留着对比 |

## 怎么改

1. 装 MagicaVoxel（免费，官网 https://ephtracy.github.io/ ）。
2. 用它打开上面的文件。打开就是拼好的整个人，**每个身体部位是一个单独的物件**（名字见下表）。
3. 在大纲（Outline）里选中一个部位，进编辑模式改：加格子、删格子、刷颜色都行。
4. `Ctrl+S` 存盘。

## 看效果

双击这个文件夹里的 **`打开游戏看效果.bat`**：浏览器会打开游戏，直接进据点，镜头拉近跟着主角，走一走、砍一刀就能看到动作。也可以用桌面的 `不见刀_白发女模型.html`（或网页版地址加 `?lab`）看各个招式。
开着它的时候，MagicaVoxel 每存一次，游戏自动刷新。看完关掉那个黑窗口。

## 规矩（不守的话动作会错位）

1. **别挪动、别旋转、别改名**任何物件——每个部位跟着自己的关节动，挪了位置，抬手时手会飞出去；改了名字游戏就认不出来。
2. **别改物件框的大小**（Resize）。框已经在人的四周留了 8 格空，够画。
3. 想让新加的东西跟着哪个部位动，就画在**那个部位的物件里**。比如斗笠上加一根羽毛，要画在 `hat` 里，不能画在 `head` 里。
4. 颜色随便换、随便加（一个文件最多 255 种颜色）。
5. 细格子的一格 = 3.5 厘米，人大约 58 格高；旧版一格 7 厘米。脚底就是框的底。

## 部位名字

「左」「右」是**她自己的**左右（她面朝你时，她的左手在你的右边）。

| 物件名 | 部位 |
|---|---|
| `hips` | 胯 |
| `spine` | 腰 |
| `chest` | 胸、肩 |
| `neck` | 脖子 |
| `head` | 头、脸、蒙眼布 |
| `hat` | 斗笠（白发造型里是脑后一小截红发绳） |
| `armL` `foreL` `handL` | 左上臂、左小臂、左手 |
| `armR` `foreR` `handR` | 右上臂、右小臂、右手（握刀那只） |
| `weapon` | 刀柄和刀环（握在手里那段） |
| `blade` | 刀身（收刀时会藏起来） |
| `legL` `shinL` `footL` | 左大腿、左小腿、左脚 |
| `legR` `shinR` `footR` | 右大腿、右小腿、右脚 |
| `bfA1` `bfA2` `bfA3` | 蒙眼布的一条飘带，从根到梢一节一节 |
| `bfB1` `bfB2` | 蒙眼布的另一条飘带 |
| `hrA1` `hrA2` `hrA3` | 白发的发尾，一节一节（只有白发造型有） |
